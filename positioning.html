🎯 STP｜Segmentation × Targeting × Positioning

S｜Segmentation

市場の切り分け（属性 × 課題）
  • 業種：教育/コンサル/士業/治療院/サロン/制作会社/スタートアップ
  • 規模：従業員5〜50名／月人件費300〜1000万円
  • 意思決定：オーナー型（社長＝決裁者＝現場）
  • IT成熟度：SaaSは導入したが活用しきれていない／Excel・Sheets多用／属人化が深刻
  • AI活用：ChatGPT契約済だが業務に組み込めていない
  • 過去経験：受託開発で痛い目／kintone挫折／高額コンサル疲れ
  • 感情：「人を増やしたくない」「AIで何とかしたい」「でも何から手を付けるか分からない」

T｜Targeting

狙う第一ターゲット（最初の100社）
  • 🎯 人件費 月300〜500万円のオーナー企業
  • 🎯 「AIで業務を変えたい」と本気で言ってる経営者
  • 🎯 Claude Codeを触れる or 触れる人材1名以上を確保できる
  • 🎯 SaaSに月10万以上払っているが効果実感が薄い
  • 🎯 OGSM・KPIを言語化したいと思ってる
  • 🎯 属人化に危機感（キーパーソン1人に依存）
  • 🎯 柳井塾既存講座生＋奥村PJ・徳武JV経由＋片寄せ先生紹介
  • 除外：大企業（決裁が遅い）／オーナーがITアレルギー／月人件費100万未満（ROI出ない）

P｜Positioning

市場でのユニークな立ち位置
  • カテゴリー：「AI右腕化サービス」（新カテゴリー）
  • 1行：オーナーがClaude Codeで業務全体をUI化し、人件費を3ヶ月で1/3にするメソッド
  • SaaSとの違い：汎用テンプレでなく、自社業務に100%フィット
  • ノーコードとの違い：単機能でなく、業務全体をHub化
  • 受託開発との違い：1年・1500万円でなく、3ヶ月・月10万円
  • AI単体との違い：単発質問でなく、業務に深く根を張る
  • コンサルとの違い：助言でなく実装まで届く（Claude Codeが手を動かす）
  • 強烈な違い：オーナー自身が育てる主導権を持つ

📝 ポジショニングステートメント（PS）

▼ 公式PS（社外向け1枚）
人件費削減を本気で目指す、月人件費300〜1000万円のオーナー企業にとって、
柳井塾の「AI右腕化メソッド」は、
SaaS（汎用すぎる）／ノーコード（単機能止まり）／受託開発（重く遅い）と異なり、
Claude Code でオーナー自身が業務全体をUI化し、
3ヶ月で人件費を1/3に圧縮する実証済みメソッドである。
なぜなら、柳井塾自身が月300万→100万を達成し、その全プロセスをテンプレ化しているからだ。
▼ 短縮版（広告/SNS用1行）
SaaSでもなく、受託でもなく、AIでもない。
オーナーが Claude Code で業務全体をUI化する。
3ヶ月で人件費1/3。

⚡ コア差別化要素（PSの裏付け3点）

1️⃣ 自社実証（柳井塾が顧客第1号）

月人件費 300万 → 100万（▲66%）／3ヶ月で達成済み。
失敗パターン・成功パターンを全テンプレ化。
「やってみた」ではなく「やり切った」のメソッド。

2️⃣ オーナー主導（外注依存ゼロ）

受託開発・SIer・コンサルと違い、オーナー自身がClaude Codeで業務をUI化する。
主導権・進化スピード・コスト全てがオーナーに残る。

3️⃣ 業務全体カバー（部分最適禁止）

営業・経理・人事・SNS・PDCA・コンテンツ制作の全領域を統一デザインのHubでカバー。
SaaSの寄せ集め地獄から脱出。

4️⃣ OGSM必須化（数値で語る）

1PJ起票時に必ずOGSM 1ページ作成。
属人的判断・なんとなく改善を撲滅。
3ヶ月後の数値Before→Afterが必ず提示される。

5️⃣ メタプロセス標準化

「PJ進めながらUIを育てる」標準サイクル。
1PJ完了 = Hub1個誕生 = 翌PJのテンプレ。
導入が進むほど構築時間が76%短縮されていく。

6️⃣ AI×人の役割分離

Claude Code：実装・データ取込・レポート生成
オーナー：判断・優先順位・PDCA
スタッフ：例外対応・顧客接点。
AI不可能な業務だけ人間が残る設計。

👤 拡張提案｜個人事業主・フリーランス版（v1.1）

「人件費」がない一人プレイヤーには、"自分の時間"が最大コスト。
法人版を簡易化して「時間取り戻し→売上倍増」に翻訳すれば、TAM（市場規模）が10倍に拡大する。

🔁 軸の翻訳

法人：人件費削減（¥300→100万/月）
個人：作業時間削減（160h→40h/月）→ 浮いた120hを売上創出に転用
→ 売上1.5〜3倍になる構造（時給単価アップ）

🎯 個人版の本質的価値

1人で全業務を回す = 完全な属人化＝外注時の引継ぎ困難。
個人版Hubを作っておけば、将来法人化・スタッフ採用・外注時にそのまま渡せる資産になる。
Hubは「未来の自分の右腕」への先行投資。

⚠️ 個人版の落とし穴と対策

落とし穴：3ヶ月続けられる人が少ない（自分以外の強制力がない）
対策：オンライングループコーチング型／週1チェックイン／コミュニティ運営／実装代行オプション併用
